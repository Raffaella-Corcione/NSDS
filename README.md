# NSDS
Networked Software for Distributed Systems coursework - Polimi, a.y. 2025/2026. Final grade: 30/30.

Collection of projects and laboratory exercises, exploring various paradigms of distributed computing. 

### Akka
The Actor model, a lock-free concurrency paradigm based on message passing. The concepts of location transparency, asynchronous communication and fault tolerance via supervision hierarchies.

### Apache Spark
Large-scale data analytics: the Map-Reduce framework, dataflow programming model, task and data parallelism. Batch, streaming and structured streaming data processing. RDDs: trasformations and actions, locality, lineage. SparkSQL. The notion of time in stream processing.

### Apache Kafka
Middleware for asynchronous event-based communication. Producer-consumer (publish-subscribe) paradigm. Space, synchronization and time decoupling. Topic-based communication: brokers, partitions, replication, consumer groups. The concepts of "at-most-once", "at-least-once", "exactly-once" semantics. Transactions.

### Node-Red
The computing continuum and the flow-based programming model. Asynchronous execution and non-deterministic scheduling. Networking with UDP sockets and MQTT.

### MPI
HPC distributed scenarios. Communicators, groups and ranks. Point-to-point communication: blocking calls, ordering guarantees, deadlocks, dynamic receiving. Collective communication: barrier synchronization, broadcast, reduce, scatter, gather, creation of new groups and communicators.

### IoT with Contiki-ng
Computing, communication and energy constraints of IoT devices. Reliability concerns. Software architectures (cloud-centric IoT, embedded IoT OS). The protothread concurrency model (sequential, single-stack semantics) vs the event-driven model (asynchronous callbacks). Cooperative scheduling with protothreads. Timers and the clock module. Simulation using COOJA. IoT networking: the protocol stack, RPL, MQTT.
